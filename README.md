# City Builder — DirectX 12 starter engine

Минимальный Win32/DirectX 12 прототип: голубое небо, зелёная платформа, куб и неподвижное солнце. Сцена использует направленный свет и отдельный проход shadow map с PCF-фильтрацией теней от куба на платформу.

## Управление камерой

| Клавиши | Действие |
| --- | --- |
| `W` / `A` / `S` / `D` | движение вперёд / влево / назад / вправо в горизонтальной плоскости |
| `R` / `F` | увеличить / уменьшить высоту камеры |
| `Q` / `E` | повернуть камеру влево / вправо вокруг её собственной позиции |
| `T` / `G` | увеличить / уменьшить поле зрения |
| `Space` | переключить вид: строго сверху или горизонтально |
| `Esc` | выйти из приложения |

## Структура

```text
assets/shaders/  HLSL: освещение и shadow map
src/core/        цикл приложения и Win32-окно
src/graphics/    устройство, swap chain, камера и геометрия сцены
src/math/        компактные векторы и матрицы для сцены
```

## Сборка

Нужны Windows 10/11, Visual Studio 2022 с компонентом **Desktop development with C++**, Windows SDK и CMake 3.21+.

```powershell
cmake -S . -B build -G "Visual Studio 17 2022" -A x64
cmake --build build --config Debug
.\build\Debug\CityBuilder.exe
```

При запуске шейдер копируется рядом с `.exe` в папку `shaders`.
